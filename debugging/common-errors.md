# Erros comuns

| Erro | Prevenção |
|---|---|
| Variável não inicializada | Inicialize sempre |
| Índice inválido | Respeite `0..size()-1` |
| Overflow | Use `long long` |
| Divisão inteira | Converta antes da divisão |
| Estrutura vazia | Teste `empty()` |
| Loop infinito | Atualize a variável de controle |
| Complexidade alta | Compare com os limites de `N` |
