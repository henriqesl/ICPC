# Matemática rápida

- Par + par = par; ímpar + ímpar = par; par + ímpar = ímpar.
- `gcd(a, b)` calcula o MDC; `lcm(a, b) = a / gcd(a,b) * b`.
- Para testar primo até `x`, basta testar divisores até `sqrt(x)`.
- Um quadrado perfeito possui quantidade ímpar de divisores.
- Use `long long` quando produtos ou somas puderem passar de `2 * 10^9`.
- Probabilidade = casos favoráveis / casos possíveis quando são equiprováveis.
